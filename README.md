# Telegram-бот для поиска музыкальных заказов

Бот отслеживает новые текстовые сообщения в группах и каналах, в которых состоит пользовательский аккаунт Telegram, ищет заданные ключевые слова и отправляет совпадения владельцу бота.

## Требования

- Python 3.10 или новее
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)
- API ID и API Hash приложения Telegram с [my.telegram.org](https://my.telegram.org)
- Пользовательский аккаунт Telegram, который может читать нужные группы и каналы

## Настройка

Откройте PowerShell в папке проекта и создайте виртуальное окружение:

```powershell
py -m venv .venv
```

Создайте `.env` на основе примера:

```powershell
Copy-Item .env.example .env
```

Заполните `.env`:

| Переменная | Что указать |
| --- | --- |
| `BOT_TOKEN` | Токен бота от BotFather |
| `OWNER_ID` | Ваш числовой Telegram ID — сюда бот отправляет уведомления |
| `API_ID` | `api_id` приложения с my.telegram.org |
| `API_HASH` | `api_hash` приложения с my.telegram.org |
| `SESSION_NAME` | Имя файла сессии Telethon; обычно оставьте `watcher` |
| `DB_PATH` | Путь к SQLite базе; обычно оставьте `bot.db` |
| `CELERY_BROKER_URL` | URL Redis для Celery; по умолчанию `redis://localhost:6379/0` |
| `CELERY_TIMEZONE` | Часовой пояс расписания; по умолчанию `Europe/Moscow` |

Не публикуйте `.env` и файл сессии Telethon: они содержат секреты и дают доступ к аккаунтам.

## Установка и запуск

В PowerShell из папки проекта выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

При первом запуске Telethon запросит в консоли номер телефона аккаунта, код подтверждения из Telegram и, если включена, пароль двухэтапной аутентификации. После авторизации рядом с проектом появится файл сессии `watcher.session`. Следующие запуски обычно не требуют повторного входа.

Остановить бота можно сочетанием `Ctrl+C`.

## Еженедельная очистка заказов

Для очистки заказов по понедельникам в 00:00 по московскому времени нужны запущенный Redis и два отдельных процесса Celery. По умолчанию Celery подключается к `redis://localhost:6379/0`; при другом адресе задайте `CELERY_BROKER_URL` в `.env`.

В отдельных окнах PowerShell из папки проекта запустите:

```powershell
.\.venv\Scripts\celery.exe -A celery_app:app worker --pool=solo --loglevel=INFO
.\.venv\Scripts\celery.exe -A celery_app:app beat --loglevel=INFO
```

Celery Beat запускает задачу `clear_orders`, которая удаляет все записи из таблицы `orders`. Остальные данные базы (ключевые слова, настройки и разрешённые чаты) сохраняются.

## Использование

1. Откройте бота в Telegram и отправьте `/start`. На главном экране показаны статус уведомлений, режим чатов и количество заказов; счётчики заказов и ключевых слов есть и на кнопках меню. Разделы меню обновляются в одном сообщении: при переходе прежний экран заменяется новым, чат не засоряется копиями меню.
2. В **Все заказы** просматривайте сохранённые сообщения, открывайте исходный пост по ссылке или удаляйте запись. Список разбит на страницы.
3. В разделе **Ключевые слова** добавьте слова или части слов. Поиск не учитывает регистр; каждое слово можно отправить с новой строки или разделить запятыми.
4. В **Настройки → Разрешённые чаты** укажите ID групп и каналов, из которых нужно получать уведомления. Бот проверит, что ID существует среди групп и каналов, доступных аккаунту Telethon. Удалите чат нажатием на его кнопку.
5. В этом же разделе нажмите **«Где найти ID чата?»** для инструкции по Telegram Desktop.
6. Убедитесь, что аккаунт Telethon вступил в выбранные группы/каналы и может читать сообщения.

При пустом списке разрешённых чатов бот рассматривает сообщения из всех доступных аккаунту Telethon групп и каналов. При непустом списке — только из добавленных чатов. Сообщения без настроенных ключевых слов уведомления не вызывают. Включать и выключать отправку уведомлений можно в настройках бота. К уведомлению прикладывается ссылка на исходное сообщение, если Telegram предоставляет для этого чата ссылку.

## Где хранятся данные

- `bot.db` — ключевые слова, список разрешённых чатов и найденные сообщения.
- `watcher.session` — авторизованная сессия пользовательского аккаунта Telethon.
- `watcher.session-journal` — временный файл, который Telethon может создать во время работы.
- `.env` — токены и настройки запуска.

Не удаляйте файл сессии, если хотите сохранить авторизацию. Не передавайте его другим людям. Файлы `.env`, `.venv`, `*.session` и `*.session-journal` не должны попадать в репозиторий.
